# نظام إدارة المتاجر الآشوري (Ashur Store Management System)

نظام شامل لإدارة المتاجر والأعمال التجارية مبني بتقنية Flutter مع دعم كامل للغة العربية والتصميم الآشوري الأصيل.

## 🌟 الميزات الرئيسية

### 📊 إدارة شاملة
- **إدارة المخزون**: تتبع المنتجات والكميات والأسعار
- **إدارة العملاء**: قاعدة بيانات العملاء والمجموعات
- **إدارة الفواتير**: إنشاء وتتبع الفواتير والمدفوعات
- **إدارة المصروفات**: تتبع المصاريف والتكاليف
- **إدارة الإيجارات**: متابعة عقود الإيجار والمدفوعات
- **إدارة الصيانة**: طلبات الصيانة والمتابعة
- **إدارة الاشتراكات**: أنواع الاشتراكات والتجديد

### 👥 إدارة المستخدمين والأدوار
- نظام مصادقة متقدم مع Firebase
- إدارة الأدوار والصلاحيات
- تبديل الأدوار الديناميكي
- نظام الجلسات الآمن

### 📱 تصميم متجاوب
- دعم جميع أحجام الشاشات
- تصميم متجاوب للهواتف والأجهزة اللوحية
- واجهة مستخدم حديثة وسهلة الاستخدام

### 🎨 التصميم الآشوري
- ألوان وتصاميم مستوحاة من التراث الآشوري
- رمز اللاماسو (الثور المجنح) كشعار
- دعم كامل للغة العربية مع RTL

### 💰 نظام التنسيق المتقدم
- تنسيق الأرقام والعملات تلقائياً
- دعم عملات متعددة (IQD, SAR, USD, EUR)
- فاصل الآلاف الذكي
- تنسيق التواريخ والأوقات

## 🛠 التقنيات المستخدمة

### Frontend
- **Flutter 3.9+**: إطار العمل الرئيسي
- **Dart**: لغة البرمجة
- **Flutter Bloc**: إدارة الحالة
- **Get It**: حقن التبعية
- **Flutter ScreenUtil**: التصميم المتجاوب

### Backend & Database
- **Firebase Auth**: المصادقة والأمان
- **Cloud Firestore**: قاعدة البيانات
- **Firebase Storage**: تخزين الملفات

### UI/UX
- **Material Design 3**: نظام التصميم
- **Custom Assyrian Theme**: الثيم الآشوري المخصص
- **Responsive Framework**: التجاوب مع الشاشات
- **RTL Support**: دعم الكتابة من اليمين لليسار

### Additional Features
- **Cached Network Image**: تحسين الصور
- **PDF Generation**: إنشاء التقارير
- **QR Code**: الباركود والـ QR
- **Charts**: الرسوم البيانية
- **File Picker**: اختيار الملفات
- **Permissions**: إدارة الصلاحيات

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Flutter SDK 3.9.0 أو أحدث
- Dart SDK 3.0.0 أو أحدث
- Android Studio أو VS Code
- حساب Firebase مع المشروع المُعد

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone [repository-url]
cd ashur
```

2. **تثبيت التبعيات**
```bash
flutter pub get
```

3. **إعداد Firebase**
- إنشاء مشروع Firebase جديد
- تفعيل Authentication و Firestore
- تحميل ملفات الإعداد:
  - `google-services.json` للأندرويد
  - `GoogleService-Info.plist` للـ iOS
- تشغيل FlutterFire CLI:
```bash
flutterfire configure
```

4. **تشغيل التطبيق**
```bash
flutter run
```

## ⚙️ الإعداد والتخصيص

### إعداد Firebase
1. إنشاء مشروع Firebase
2. تفعيل Authentication (Email/Password, Google)
3. إنشاء قاعدة بيانات Firestore
4. إعداد قواعد الأمان
5. تفعيل Firebase Storage

### إعداد الثيم الآشوري
يمكن تخصيص الألوان والتصميم من خلال:
- `lib/core/theme/assyrian_theme.dart`
- `lib/core/theme/app_colors.dart`

### إعداد التنسيق
تخصيص تنسيق الأرقام والعملات من:
- `lib/core/services/formatting_service.dart`
- إعدادات التنسيق في التطبيق
